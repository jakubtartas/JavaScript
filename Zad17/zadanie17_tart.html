1. Wymień cztery sposoby wyprowadzania danych w JavaScript.

Przykładowe sposoby prezentowania danych użytkownikowi:

  • za pomocą document.write(), który zapisuje treść do dokumentu HTML;
  • za pomocą okna komunikatu alert();
  • do elementów formularza, na przykład pola tekstowego;
  • do komórek tabeli lub innych elementów strony.

2. Czym jest funkcja w JavaScript? Omów, używając czterech podpunktów.

  • Funkcja to nazwany lub przypisany do zmiennej blok instrukcji wykonujący określone zadanie.
  • Jej kod wykonuje się po jej wywołaniu, na przykład przez podanie nazwy i nawiasów: oblicz().
  • Funkcja może przyjmować argumenty, które są przekazywane do jej parametrów i wykorzystywane w jej wnętrzu.
  • Funkcja może zwrócić wynik za pomocą słowa kluczowego return; jeśli nie użyje return, zwraca undefined.

Przykład funkcji z argumentami i zwracaną wartością:

function suma(a, b) {
    return a + b;
}

var wynik = suma(2, 3); // wynik ma wartość 5

3. Omów metody getElementsByName, getElementById i getElementsByTagName. Możesz użyć tabeli.

Metoda Opis
document.getElementById("nazwa") Zwraca element o podanej wartości atrybutu id. Identyfikator powinien być unikalny na stronie.
document.getElementsByTagName("p") Zwraca kolekcję elementów o podanej nazwie znacznika, na przykład wszystkie znaczniki <p>.
document.getElementsByName("nazwa") Zwraca kolekcję elementów, których atrybut name ma podaną wartość, na przykład elementów formularza.

4. Omów właściwości innerHTML, innerText i className (każdą osobno).

  • innerHTML odczytuje lub ustawia zawartość elementu jako kod HTML. Wstawione znaczniki są interpretowane przez przeglądarkę.
  • innerText odczytuje lub ustawia tekst widoczny w elemencie; ustawiona wartość jest traktowana jako tekst, a nie kod HTML.
  • className odczytuje lub ustawia wartość atrybutu class, czyli klasę lub klasy CSS elementu.
