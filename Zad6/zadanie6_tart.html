1) Rodzaje okienek
alert - wyświetla okno dialogowe z informacją i przyciskiem OK.
prompt - tworzy okno, w którym użytkownik może wpisać wartość, a następnie ta wartość jest zwracana do programu.
confirm - służy do potwierdzenia jakiejś decyzji przez użytkownika, stąd nazwa confirm.

2) Konwersja liczb
Wczytanie danych za pomocą prompt odbywa się jako ciąg znaków, czyli String. Dlatego aby wykonać obliczenia, konieczna jest konwersja zmiennej na liczbę.
parseFloat(zmienna) - konwersja zmiennej do typu float (liczba zmiennoprzecinkowa).
parseInt(zmienna) - konwersja zmiennej do typu int (liczba całkowita).
toString(zmienna) - konwersja zmiennej do typu tekstowego.

3) Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad
1. Nazwa zmiennej musi zaczynać się od litery, znaku $ lub _. Może zawierać tylko litery bez polskich znaków, cyfry oraz znaki $ i _.
Poprawne nazwy zmiennych: zmienna1, $wynik, _rozmiar, wynik1, Rekord, $_gracz
Błędne nazwy zmiennych: 1zmienna, wynik gry, wysokosc&szerokosc, wynik.rekord, &gracz, wysokość, imie+nazwisko
2. Wielkość liter ma znaczenie. Rekord i rekord to dwie różne zmienne. To częsta przyczyna błędów w kodzie początkujących programistów.
3. Należy nie używać słów kluczowych JavaScript jako nazw zmiennych.

4) Omów typy zmiennych w JavaScript
W JavaScript nie ma możliwości definiowania różnych typów zmiennych tak jak w C++, ponieważ typy zmiennych są określane dopiero podczas ich przypisywania.
Number - typ liczbowy, obejmuje liczby całkowite i zmiennoprzecinkowe.
String - typ tekstowy.
Boolean - typ logiczny, przyjmuje wartości true i false.
Null - pusta zawartość.
Undefined - typ niezidentyfikowany, zmienna nie ma przypisanej wartości.
Object - obiekt.
